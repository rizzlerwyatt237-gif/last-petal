# Download Last Petal

## Windows

Download the repository as a ZIP from GitHub:

1. Open the Last Petal repository.
2. Click **Code**.
3. Click **Download ZIP**.
4. Extract the ZIP.
5. Open the extracted `index.html` file in your browser.
6. Click **START** to play.

The game currently runs directly in a web browser, so no installer is required.

## Controls

- **W / A / S / D** — Move
- **Arrow Keys** — Move
- **Enter** — Continue dialogue
- **CONTINUE** — Continue dialogue with the mouse

## Important

Last Petal is an original fan-game prototype. The public repository does not include Undertale's original game files, `data.win`, or extracted Undertale assets.
